# Getting help

- Read the [README](./README.md) and setup instructions first.
- Search existing [issues](https://github.com/madhav-manchanda/PocketPrinter/issues)
  before opening a new one.
- Use GitHub Issues for reproducible bugs and feature requests.
- Include your Android version, printer make/model, PocketPrint version, and
  redacted logs when relevant.
- Never post passwords, access tokens, private documents, or personal data.
- Report security vulnerabilities privately using [SECURITY.md](./SECURITY.md).
